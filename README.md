# codediff

A terminal diff reviewer for LLM-agent code changes. Work in progress.

## Status

Under active development. No stable release, no install instructions,
no backwards compatibility promises. If you're here, you're early.

## Building

Requires Rust (pinned in `rust-toolchain.toml`) and a C compiler.

```sh
cargo build --release
./target/release/codediff --help
```
